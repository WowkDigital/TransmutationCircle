# ✦ Transmutation Circle Generator ✦

A professional-grade alchemical design studio for creating intricate Transmutation Circles inspired by the world of *Fullmetal Alchemist*. This tool allows for the generation, customization, and export of complex geometric alchemical patterns.

![License](https://img.shields.io/badge/license-MIT-gold.svg)
![Version](https://img.shields.io/badge/version-1.0.0-gold.svg)
![Theme](https://img.shields.io/badge/theme-Alchemical-red.svg)

## ✨ Features

- **Preset Library**: Quickly load iconic circles like Human Transmutation, Flame Alchemy, and Metal Binding.
- **Geometric Precision**: Control the number of rings, polygon sides (3-8), inner stars, and rotation.
- **Dynamic Elements**: 
  - Toggle alchemical text (Inner/Outer)
  - Customizable nodes and cross-lines
  - Dashed rings and double outer borders
  - Hatch fills for depth
- **Symbol Library**: Choose from a variety of alchemical symbols for the center of your circle.
- **Visual Themes**: Multiple aesthetic themes including Alchemical Gold, Parchment White, Blood Circle, Azure Seal, and Verdant Alchemy.
- **Export Capabilities**: High-quality SVG export for use in digital art, printing, or further design work.
- **Randomization Engine**: Generate unique, unexpected alchemical patterns with a single click.

## 🚀 Getting Started

### Prerequisites

This is a static web application. No server-side environment is required.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/transmutation-circle-generator.git
   ```
2. Navigate to the project directory:
   ```bash
   cd transmutation-circle-generator
   ```
3. Open `index.html` in any modern web browser.

## 🛠️ Built With

- **HTML5/CSS3**: Semantic structure and rich, responsive styling.
- **Vanilla JavaScript**: Modular ES6+ logic for geometric calculations and rendering.
- **SVG**: Vector-based rendering engine for infinite scalability.
